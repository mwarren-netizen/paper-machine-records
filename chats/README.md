# Chat logs

Seven anonymised conversations that mark the turning points of the Paper Machine. Each page names its date and what happened in it. The operator's name and identifying details are replaced; descriptions of the three reference manuscripts are omitted and marked. Where the operator edited a message, the abandoned branch is kept in place and marked.
